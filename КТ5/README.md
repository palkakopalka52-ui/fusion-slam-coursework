# КТ5 · FusionLab, станции F10–F12

[Ветка с кодом, весами и отчётом F10–F12](https://github.com/palkakopalka52-ui/fusion-slam-coursework/tree/kt5/wheel-correction)

[Выполненный ноутбук](F10-F12.ipynb) · [Отчёт](Отчёт.md) · [Экспорт библиотеки с весами и тестом](fusionlab_student_increment.zip)

Откройте `F10-F12.ipynb` в Colab и выполните все ячейки на CPU. Ноутбук сам распакует LSTM и бустинг из F9, пересчитает калибровку, проверит 90 сочетаний и соберёт архив. Обучать заново исходные модели при этом не требуется. Готовый распакованный экспорт находится в `fusionlab_release/`. В `validation.csv` сохранена исходная валидация из F9. Таблицы `f10_*`, `calibration.csv` и `test_*` вычислены в этом продолжении. При чтении CSV в pandas используйте `keep_default_na=False`, чтобы сохранить название режима `null`.

## Проверка готового экспорта

Из каталога КТ5, в Python 3.12:

```bash
python -m pip install -r fusionlab_release/requirements.txt
python fusionlab_release/smoke_test.py
python integration.py
```

`smoke_test.py` загружает обе модели и вычисляет оценку на новом маршруте 6000. `integration.py` использует соседние папки КТ3 и КТ4, на новом маршруте 6021 подаёт поправки в собственный плоский граф и сравнивает три политики демпфирования. Результат записывается в `integration.csv`. Весь основной F12 повторяется из ноутбука без соседних папок.

## Происхождение

В финальном спринте для F10 разрешены CNN, MLP и LSTM. В исходной ячейке выбрана CNN. Выбор LSTM сделан до F12 по [валидации F9](fusionlab_release/validation.csv). RMSE продольной ошибки составила 0,0920 м у LSTM, 0,0972 м у CNN, 0,1136 м у MLP и 0,0836 м у контрольного бустинга.

Стенд, генератор и исходные модули F1–F9 взяты из учебного ноутбука «FusionLab — эксперимент F9». LSTM и контрольный бустинг загружены из сохранённого после F9 архива `FusionLab_F9_models.zip`. По его манифесту архитектура для продолжения — LSTM, вход имеет форму 8 × 2, каналы — нагрузка и вибрация. Обучение использовало маршруты 1000–1119, выбор по валидации — 2000–2023. Новая реализация адаптера расположена в `fusionlab/wheel_channel.py`. Она сопоставляет концы интервалов, калибрует доверие и заменяет только продольный компонент колёсного фактора. Совместимость с интерфейсом учебного ноутбука обеспечивает `fusionlab/fusion_adapter.py`.
