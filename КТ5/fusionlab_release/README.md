# FusionLab · учебный инкремент

Плоский синтетический SLAM, известные соответствия, синхронные метрические факторы.
`geometry2d`, `linear_solver`, `slam_core` — геометрия и решатели; `synthetic` — стенд; `learned_sensor` — предикторы; `fusion_adapter` — калибровка и исправление входов.
В рабочем backend Keras запустите из этой папки `python smoke_test.py`. `config.json` хранит версии, разбиение и коэффициенты отдельных сценариев. Коэффициент не переносится автоматически в неизвестный режим.
Истина нужна только для обучения/оценки. Синтетические испытания не подтверждают физическую надёжность или универсальный выигрыш.
Сводные таблицы содержат свежий прогон пяти тестовых маршрутов в каждом из трёх режимов.
